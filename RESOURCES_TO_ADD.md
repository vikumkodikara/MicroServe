# Resources to add

This project has placeholder files for the Service Requests UI. To complete the integration, add the following assets.

## Fonts (place in `app/src/main/res/font/`)
- inter_bold.ttf
- inter_semibold.ttf
- inter_light.ttf
- lato_bold.ttf
- lato_medium.ttf

Download from Google Fonts (Inter, Lato) and copy the required `.ttf` files into the font folder.

## Next steps
1. Replace `app/src/main/res/layout/activity_request_main.xml` with the actual `android_layout_request_main.xml` content.
2. Add font files into `res/font/`.
3. Add image assets into `res/drawable/`.
4. In Android Studio: Sync Project with Gradle Files → Rebuild Project.
